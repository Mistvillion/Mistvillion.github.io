# Mistvillion's Home

Context for the personal homepage at `sparklerain.top`: the pages a visitor can browse, and the note cards that link out to published course notes.

## Language

**Notes page**:
The homepage page where the visitor finds a record of notes taken during courses and the note cards for those courses.
_Avoid_: Notes link, notes interface

**note card**:
A capsule-shaped link on the Notes page that pairs a course note collection's title with a short introduction.
_Avoid_: pill, capsule, item, note link

**course note**:
A collection of notes published for a single course and linked from a note card.
_Avoid_: lecture note, course material

**course**:
The academic subject that a course note collection is based on.
_Avoid_: class, subject
